# v0.1.3 — Hyprlock con PAM del sistema

Fecha: 2026-11-23

## Agregado

- Hyprlock del sistema (`/usr/bin/hyprlock`) como dependencia de
  `mytical-desktop`.
- PAM propio de Hyprlock en `mytical-session`.

## Cambiado

- El desbloqueo usa el PAM del sistema, no los módulos PAM de Nix.
- La sesión resuelve `hyprlock` desde APT.

## Corregido

- **Desbloqueo de Hyprlock:** la contraseña correcta ya no se rechaza.
- Se elimina el fallo `pam_unix(hyprlock:auth): authentication failure` causado
  por la combinación Hyprlock-Nix + Ubuntu.

## Removido

- `hyprlock` del perfil Nix.
- Dependencia del binario Nix para el bloqueo de pantalla.

## Verificación

- `which hyprlock` → `/usr/bin/hyprlock`.
- Desbloqueo confirmado por el usuario.
- 30 tests unitarios y tests de paquete.
