# v0.1.0 — Mytical V1.0 Preview

Fecha: 2026-11-17

## Agregado

- Overlay instalable sobre Ubuntu 26.04 con APT + Nix.
- `mytical-session`, `mytical-welcome` y `mytical-desktop`.
- SDDM con una única sesión Mytical.
- Nix 26.05 y Home Manager.
- Kitty con paleta adaptativa.
- Waybar, dunst, hypridle, wallpapers dinámicos y tema SDDM.
- Repo APT local firmado.
- Primer arranque y gestión inicial de wallpapers.

## Cambiado

- Hyprland y apps de usuario pasan a Nix 26.05.
- SDDM sustituye a GDM.
- La sesión canónica es `/usr/share/wayland-sessions/mytical.desktop`.

## Corregido

- Enlaces de `setup.py` para sesión, temas y wallpapers.
- Separación APT/Nix y matriz de propiedad.

## Removido

- GNOME Shell, GDM y `ubuntu-session` del escritorio.
- Dependencia de PPAs de Ubuntu 24.04.
- `graphify-out` del árbol de release.

## Verificación

- 12 tests unitarios.
- `make -C distro test`.
- SDDM solo con Mytical.

## Artefactos

- Tag `v0.1.0`.
- Snapshot APT local.
