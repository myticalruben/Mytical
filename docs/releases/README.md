# Notas de release

Cada versión publicada tiene una nota con cuatro bloques obligatorios:

- **Agregado**
- **Cambiado**
- **Corregido**
- **Removido**

La nota se escribe antes de crear el tag y se versiona en el mismo commit.
Para una versión nueva, copiar `TEMPLATE.md` a `vX.Y.Z.md` y completar.

Las notas describen lo que cambió para el usuario y lo que dejó de existir;
no repiten el changelog interno commit por commit.
